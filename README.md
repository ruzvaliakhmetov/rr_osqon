# RR Osqon

RR Osqon – a small display sans-serif font created as an experiment in alternative alphabet design and text readability.

![Example](images/example-white.svg#gh-dark-mode-only)![Example](images/example-black.svg#gh-lightmod-mode-only)

## About

This typeface is designed for setting Bashqort texts in the Latin-based orthography of the 1920s–30s, known as Yañalif. Rather than rewriting or re-encoding historical texts, the project preserves their original character set and offers alternative letterforms through stylistic sets. This allows the same text to exist in two readings: the original historical form and a more accessible contemporary interpretation, while keeping the underlying encoding unchanged.

For example, a text encoded with the original character Ҍ can, with a stylistic set enabled, display a more familiar form closer to C, such as Ç. In this way, the text remains historically intact while gaining a more legible contemporary layer.


It includes one display style and a stylistic set with alternate forms of:

`Ь` — `U+042C` — **CYRILLIC CAPITAL LETTER SOFT SIGN**

`ь` — `U+044C` — **CYRILLIC SMALL LETTER SOFT SIGN**

`I` — `U+0049` — **LATIN CAPITAL LETTER I**

`Ҍ` — `U+048C` — **CYRILLIC CAPITAL LETTER SEMISOFT SIGN**

`ҍ` — `U+048D` — **CYRILLIC SMALL LETTER SEMISOFT SIGN**

`đ` — `U+0111` — **LATIN SMALL LETTER D WITH STROKE**

`Ƶ` — `U+01B5` — **LATIN CAPITAL LETTER Z WITH STROKE**

`ƶ` — `U+01B6` — **LATIN SMALL LETTER Z WITH STROKE**

`ʙ` — `U+0299` — **LATIN LETTER SMALL CAPITAL B**
